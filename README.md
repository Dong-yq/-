# 薪资秒表

一款 Windows 桌面薪资计时小工具。设置日薪和上班时间后，实时显示已赚收入、每秒收入、工作进度和下班倒计时。可收起为迷你悬浮球，支持置顶、贴边隐藏和跨屏拖动。

无需安装，无需登录，完全离线使用。

## 快速开始

1. 将 `薪资秒表.exe` 放到一个单独的、可以写入文件的文件夹中，例如桌面上的“薪资秒表”文件夹。
2. 双击程序。如果文件名带有版本说明，直接打开对应的 `.exe` 即可。
3. 点击 **工作设置**，填写日薪、上下班时间、休息时段和工作日。
4. 点击 **保存设置**，查看今日收入。
5. 点击 **收起为悬浮球** 或右上角的 **−**，即可缩小显示。

首次启动的默认设置：日薪 **300 元**，周一至周五 **09:00—18:00**，扣除 **12:00—13:00** 的休息时间。请按自己的实际情况修改。

## 使用环境

- Windows 10 / Windows 11。
- 需要 .NET Framework 4.x，通常由系统自带。
- 不需要安装 Python、Node.js 或开发工具。
- `.exe` 不能直接在 macOS、Android 或 iPhone 上运行。

## 工作设置

| 设置项 | 填写方式 |
| --- | --- |
| 日薪 | 每个工作日的收入，单位为人民币，支持小数，例如 `300` 或 `413.97`。 |
| 上班时间 | 使用 24 小时制，例如 `09:00`。 |
| 下班时间 | 使用 24 小时制，例如 `18:30`。下班时间早于上班时间时，表示次日下班。 |
| 扣除休息时间 | 勾选后，休息时段不累计收入，并从有效工时中扣除；如果休息也计薪，可以取消勾选。 |
| 休息开始、结束 | 需位于班次内，也可以跨午夜。 |
| 工作日 | 点击星期按钮选择，至少选择一天。 |

时间输入支持英文冒号 `:`、中文冒号 `：`，也允许冒号前后有空格。以下输入都表示上午十点：

```text
10:00
10：00
10: 00
10 ： 00
```

保存时会统一为 `HH:mm` 格式。分钟需填写两位；`24:00` 无效，午夜请填写 `00:00`。上下班时间不能相同。

点击 **保存设置** 后，收入会按新设置重新计算。在设置页面按 `Enter` 也可保存。

## 悬浮球与面板操作

| 操作 | 使用方法 |
| --- | --- |
| 收起为悬浮球 | 点击面板下方的按钮，或右上角 **−**。 |
| 展开收入面板 | 单击悬浮球。 |
| 移动悬浮球 | 按住悬浮球拖动，松开后停留在落点。 |
| 移动面板 | 按住顶部标题区域拖动。 |
| 保持置顶 | 默认开启，可通过顶部准星按钮或悬浮球右键菜单切换。 |
| 隐藏或显示金额 | 点击“今日已赚”右侧的圆点按钮，或使用悬浮球右键菜单。 |
| 切换显示模式 | 窗口获得焦点时，按 `Esc` 在面板和悬浮球之间切换。 |
| 退出程序 | 点击右上角 **×**，或右键悬浮球选择 **退出秒表**。 |

右上角的 **−** 会收起为悬浮球；**×** 会退出程序。

### 贴边收起

1. 将悬浮球拖到当前屏幕的左侧或右侧边缘。
2. 移开鼠标约 **0.65 秒**，悬浮球会收起为一条窄边条。
3. 将鼠标移到边条上，恢复悬浮球；单击可展开收入面板。
4. 将悬浮球拖离边缘，或右键选择 **取消贴边收起**，即可取消自动收起。

贴边收起支持屏幕的左右边缘，顶部和底部不会自动收起。

### 跨屏使用

在扩展屏幕模式下，按住悬浮球或面板标题，将其拖到目标屏幕后松开即可。支持副屏位于主屏的左侧、右侧、上方或下方。

拖动过程中不会限制在原屏幕内；松开后，按鼠标所在的屏幕定位并处理贴边。窗口位置、显示模式和贴边状态会保存，下次启动时恢复。如果原来的屏幕已断开，程序会将窗口调整到可用屏幕内。

## 收入如何计算

```text
有效工作秒数 = 班次总秒数 − 被扣除的休息秒数
每秒收入 = 日薪 ÷ 有效工作秒数
当前收入 = 每秒收入 × 已经过的有效工作秒数
```

例如：日薪 300 元，上班时间为 09:00—18:00，休息时间为 12:00—13:00。

- 班次共 9 小时，扣除休息后为 **8 小时**，即 **28,800 秒**。
- 每秒收入约为 **0.0104 元**。
- 累计工作 4 个有效小时后，收入为 **150 元**。
- 休息期间收入停止增长，下班时累计到 **300 元**。

### 不同时段的显示

| 时段 | 收入表现 |
| --- | --- |
| 上班前 | 当前班次收入为 0。 |
| 工作中 | 按已经过的有效工作时间增长。 |
| 扣除的休息时段 | 暂停增长，休息结束后继续累计。 |
| 下班后 | 停在该班次的日薪金额，不继续增加。 |
| 非工作日 | 不开始新的计薪班次。 |

**夜班以开始上班当天判断是否为工作日。** 例如，周五 22:00—次日 06:00 的班次，会继续计算到周六早上。跨夜班次完成后，会保留该班收入，直到当天设置的下一次上班时间。

收入金额显示到“分”，采用向下截取；秒薪显示四位小数，实际计算使用未截断的精度。

这是按排班估算收入的工具，不记录实际考勤，也不计算加班、税费或扣款。

## 本地保存与分享

首次保存设置时，程序会在 `.exe` 同目录下自动创建 `Data` 文件夹：

```text
薪资秒表/
├─ 薪资秒表.exe
├─ README.md
└─ Data/
   └─ settings.json
```

`settings.json` 保存日薪、排班、金额显示状态、置顶状态、窗口位置和贴边状态。程序不联网，也不会上传这些设置。

- **自己换文件夹或换电脑：** 退出程序后，将 `.exe` 和 `Data` 文件夹一起复制，可保留设置。
- **分享给别人：** 发送 `.exe` 和本 README 即可，源码和 `Data` 文件夹都不必发送。对方首次打开后自行设置日薪和排班。
- **更新程序：** 先退出旧版，再将新版 `.exe` 放在原文件夹内，保留原来的 `Data` 文件夹，即可继续使用已保存的设置。

## 常见问题

### 为什么刚打开就已经有收入？

程序根据本机当前时间与已保存的排班计算收入。即使当天中途才打开，也会计入此前已经过的有效工作时间。

### 关闭程序或电脑睡眠后，收入会丢失吗？

重新打开时会按当前时间重新计算，不依赖程序持续运行。请保持本机日期、时间正确。

### 为什么收入没有增长？

检查当前是否处于上班前、被扣除的休息时段、下班后或非工作日，同时确认设置已保存。收入以“分”显示，秒薪较低时，需要等待几秒才能看到金额变化。

### 输入时间后提示格式错误怎么办？

使用 `09:00` 或 `09：00` 这样的 24 小时格式，分钟填写两位。检查上下班时间是否相同、休息时段是否在班次内，以及是否至少选择了一个工作日。

### 提示“薪资秒表已经在运行”怎么办？

程序一次只能运行一个实例。请先找到已有的面板、悬浮球或屏幕边条。需要换版本时，先通过右键菜单退出旧版，再打开新版。

### 提示无法保存设置怎么办？

退出程序，将它放到当前用户可写入的文件夹，例如桌面或文档文件夹，再打开。已经保存过设置时，请同时移动 `Data` 文件夹。

### 怎样恢复默认设置？

先退出程序，将 `Data/settings.json` 改名为 `settings.backup.json`，再重新打开程序。保留备份文件，可以在退出程序后改回原名来恢复原来的设置。

## 开发与构建（可选）

普通使用者只需要 `.exe`。需要修改程序时，可参考以下文件：

| 文件 | 用途 |
| --- | --- |
| `src/SalaryEngine.cs` | 排班、时间解析和收入计算。 |
| `src/MainWindow.xaml` | 收入面板、设置页面和悬浮球界面。 |
| `src/App.cs` | 拖动、跨屏、交互与本地保存。 |
| `src/FloatingDock.cs` | 贴边布局、屏幕工作区和窗口移动。 |
| `build.ps1` | 编译可执行文件。 |
| `test.ps1` | 执行计薪、布局、窗口移动和输入框渲染检查。 |

在 Windows PowerShell 中进入项目目录，运行：

```powershell
# 构建；请先退出正在运行的程序，避免 exe 被占用
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1

# 执行自动检查
powershell -NoProfile -ExecutionPolicy Bypass -File .\test.ps1
```

构建使用本机 .NET Framework 提供的 C# 编译器，不需要下载第三方依赖。
